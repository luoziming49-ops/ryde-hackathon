# Digital Native 项目导航

每次接手仅需 [AGENTS](AGENTS.md) 与 [STATUS](docs/STATUS.md)。其余资料按当前任务引用读取；项目名称尚未确定。

GitHub 协作入口：[ryde-hackathon](https://github.com/luoziming49-ops/ryde-hackathon)。仓库名用于团队协作，不代表产品定名。加入与同步记录见 [T010](docs/tasks/T010-collaboration.md)，日常操作见 [协作说明](CONTRIBUTING.md)。

| 层级 | 文件 | 何时读取 |
|---|---|---|
| 常驻入口 | [AGENTS](AGENTS.md)、[STATUS](docs/STATUS.md) | 每次接手；规则已注入则不重读 |
| 任务资料 | [框架讨论稿 T009](docs/ideas/2026-09-27-framework.md) | 当前讨论项目定位与范围 |
| 任务资料 | [资源任务包 T004](docs/tasks/T004-resources.md) | 继续背景资源确认 |
| 任务资料 | [活动任务索引](docs/TASKS.md) | 选择或切换任务 |
| 协作入口 | [协作说明](CONTRIBUTING.md)、[仓库准备 T010](docs/tasks/T010-collaboration.md) | 加入仓库、领取任务、提交与审阅修改 |
| 任务资料 | [项目简述](docs/CONTEXT.md) | 理解业务背景或形成项目简述 |
| 任务资料 | [有效决策索引](docs/DECISIONS.md) | 相关决定影响当前工作时 |

| 历史与证据 | [历史检查点与完成任务](docs/archive/LOG.md) | 追溯已完成工作 |

原始资料目录为 [背景资料](背景资料)，不是项目根目录。完整手册、邮件摘要和截图经资料索引定位；旧文档快照仅作追溯，不是现行指令。

GitHub 保存项目 Markdown 文档及协作模板；手册、原始截图、图片核验副本和旧文档快照暂留本地，已加入忽略规则。相关原件链接仅在完整本地目录中可用；共享摘要不包含个人兑换码或私人邮件全文。

新会话接续用语：

> 只读 AGENTS.md 和 docs/STATUS.md，按当前任务包接续；需要时沿相关链接读取，不加载整套背景和历史。

跨机器保存可携带完整目录，但每次工作仍只加载最小任务包。不要把“完整保存”理解为“每轮完整读取”。
