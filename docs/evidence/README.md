# Evidence — Tool Usage Screenshots

Screenshots of **WorkBuddy / CodeBuddy** usage go in this folder.

- Keep at least 3 genuine development-conversation screenshots for submission; see [official requirements](../REQUIREMENTS.md). No per-member daily quota is established in the verified requirements.
- Capture actual tasks, outputs and adoption. Written claims, prepared prompts and application screenshots do not replace real tool conversations. Evidence is still pending in this repository.
- **Never include**: redeem codes, API keys, or private email addresses.

Keep the screenshots named clearly (e.g. `2026-10-07-codebuddy-S0.png`).
