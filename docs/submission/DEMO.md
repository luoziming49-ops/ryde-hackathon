## 演示前

按[根README](../../README.md)启动本地服务，确认默认 **Simulation**。页面提供原4个基准案和3个明确标记的合成口头陈述变体。合成变体不是新真实案例，不为原案补造事实。按[本轮任务](../tasks/CONSENT-RYDE.md)完成验证后再彩排；旧报告的0001退款SGD 7.87不再是当前预期。所有证据、政策与模型模拟响应都须如实说明。本轮不增加收费调用，只有实际操作完成后才勾选彩排结果。

界面右上角可选 **中文 / English**，会记住选择。本脚本的英文按钮名对应English；用中文演示时选择中文即可。可在结果出现后切换一次，说明切换不重跑、不改变金额或Live模式，证据和审计保留原文。中文摘要不能代替原始理由及引用。

## 现场故障预案

- **本地服务不可达：** 按README检查并重启，默认127.0.0.1:8766；地址改变时同步浏览器。
- **运行503：** 最多2个并发，等已有运行结束后再试。
- **记录404：** 记录在进程内存中，重启会清空，重新运行；保持单进程。
- **模型不可用：** 明确使用Simulation；有日期的旧Live证据不等于当次成功。
- **下载拖慢演示：** 最后导出；旧审计样例必须标明来源，不能冒充当次下载。

## 问答用准确表述

**双方都认可口头同意，是否已查明事实？** 只能说明双方陈述一致；口头同意没有因此成为独立核验事实。应与其他证据及冲突一起判断。

**为什么0001不再自动建议7.87元？** 原样例没有可确认的同意事实；不能从缺少聊天推断未沟通，也不能补造“没有同意”来保留旧金额。该责任判断依赖尚未确认的信息，所以金额未确定并标记待人工。

**地图证明绕路或拥堵了吗？** 图只显示提供的坐标；偏离比例使用提供的里程，traffic是输入字段，没有接入地图服务独立验证。

**可以上传新案或自动转客服吗？** 目前页面只有预置样例；结构化/api/resolve接口不附带上传/输入页面或新案持久化。人工复核只有标记，没有客服派单、案件移交或支付。

**置信度是准确率吗？** 不是，是未校准的规则分数。当前也没有代表性客服对照实验，不宣称收益百分比。
