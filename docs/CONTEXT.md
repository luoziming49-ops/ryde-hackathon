## 题目与问题

Tencent Cloud AI CAN DO IT Hackathon Singapore 2026 由 Tencent Cloud 与 AI Singapore 联合举办。已选 Digital Native / Ryde，题目为 **Multi-Agent Autonomous Dispute Resolution System（多智能体自主争议解决系统）**。来源：[S1](sources/INDEX.md#s1)，p2、34–39。

业务问题是乘客与司机发生争议后，平台需要汇集行程、沟通、费用等证据，理解双方主张并适用政策，形成公平、透明且一致的处理结果，使多数常规争议能够自主处理。手册的成本、24–72 小时处理周期与流失描述是题目背景，不是本项目测量结果。

涉及乘客、司机及平台争议处理人员；产品的主要操作者、核心体验和具体争议类型还未选择。项目名称尚未确定。
