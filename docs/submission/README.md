## 提交前检查

- 至少3张真实 CodeBuddy 或 WorkBuddy 对话截图尚待补齐。按[提示词与记录方法](WORKBUDDY-PROMPTS.md)实际完成辅助任务，保留任务、输出和采用情况；不要用应用截图、Codex截图或重制聊天替代。
- 源码以GitHub默认main交付；源码字段在[表单文案](FORM-COPY.md)维护，分支取舍与验证见[终稿报告](../reports/FINAL-RELEASE.md)。
- 队名、队长身份及联系方式由本人补充；后续上传页限制、最终提交及回执尚待完成。截止、入口及官方要求只以[要求清单](../REQUIREMENTS.md)为准。
- 视频与公网演示是选做项：目前有脚本和本地原型，没有成片或公网部署。模型扩测按需要另行授权，不是今天整理材料的已完成项。

当前证据与政策都是演示输入；建议动作不执行支付。小样本一致性、规则置信分数及引用校验均不能替代真实业务准确率或收益验证。最新进度只在[STATUS](../STATUS.md)维护。
