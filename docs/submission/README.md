## 现场必须说明的边界

- **界面使用预置样例。** 保留原4个基准案，并新增3个明确标记的合成口头陈述变体；合成变体不是新的真实业务案例。`/api/resolve`接受结构化API请求，但没有上传或新案输入页面，也没有新案件持久化。
- **路线图是输入坐标示意。** 绕路比例来自提供的里程字段；地图没有独立核验路线或traffic交通字段。GPS和缺少聊天记录都不能单独证明“没有口头同意”。
- **双方陈述可一致、冲突或未确认。** 双方都说口头认可，仍属于双方报告，不是独立核验事实；关键同意事实仍冲突或未知、且会影响责任判断时，应标记人工复核并保持`amount=null`。原0001缺少确认，不能继续展示自动退款SGD 7.87。合成变体中，双方报告同意且无停靠为no_action / 0；报告冲突为待人工 / null；双方报告未同意且无停靠按演示规则建议7.87。三者的同意状态都基于双方报告。
- **人工复核只是标记。** 当前没有客服派单或案件移交，也不执行支付。0002仍为全额退款建议SGD 5.00；0003与DISP-002仍为no_action，不因新增同意检查一律转人工。
